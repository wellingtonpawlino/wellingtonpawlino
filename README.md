## 🚀 Projetos em destaque

### ⚡ [SPTrans Realtime Kafka](https://github.com/wellingtonpawlino/sptrans-realtime-kafka)

Pipeline de streaming em tempo real monitorando ~6.800 eventos/ciclo
da frota de ônibus de São Paulo (1.300+ linhas).

- Apache Kafka (KRaft) como message broker — desacoplamento e replay de eventos
- Stream processor com agregação em memória e batch insert no ClickHouse
- Dashboard ao vivo no Grafana com datasource provisionado automaticamente
- Infraestrutura completa via Docker Compose

> Evolução direta do projeto batch abaixo — mesma fonte, arquitetura diferente,
> propósito diferente: detectar anomalias operacionais em tempo real.

---
